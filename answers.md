### Що скаже компілятор, якщо прибрати поле year у об’єкті?
Буде помилка: Property 'year' is missing in type ... but required in type 'Book'. 
Усі обов'язкові поля мають бути вказані.

### Що станеться, якщо звернутися до book.rating без перевірки?
Для об'єкта minimalBook це поверне undefined. Якщо просто вивести через console.log(book.rating), у консолі буде undefined. 
Але якщо спробувати виконати з ним математичну операцію (наприклад, book.rating + 1) без перевірки, 
буде помилка: 'book.rating' is possibly 'undefined'.

### Чому readonly корисний саме для id, а не для rating?
id — це унікальний ідентифікатор запису в базі даних. Він створюється один раз і ніколи не має змінюватися протягом усього "життя" об'єкта. 
А рейтинг (rating) — це динамічна величина, яка може змінюватися при додаванні нових відгуків користувачів.
